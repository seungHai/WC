# 🚽 대똥여지도 (WC Map) v2.0

승인된 회원 전용 **프라이빗 화장실 위치 · 비밀번호 안내 및 실시간 제보 웹 서비스**입니다.

---

## ✨ 주요 디벨롭 내역 (v2.0)

1. **전문적인 비공개 회원제 로그인 & 관리자 계정 부여 시스템**
   - 외부 회원가입 없이 **관리자가 직접 부여한 간편 아이디 + 비밀번호**(예: `user01` / `1234`)로만 로그인 가능
   - **관리자 센터 (`👑 관리자 센터`)**: 웹 화면에서 바로 신규 사용자 계정 발급, 비밀번호 재설정, 계정 일시정지/삭제 지원
   - **카카오톡/문자 공유용 계정 안내 문구 원클릭 복사** 기능 제공
   - 로그인 상태 유지(자동 로그인) 및 내 비밀번호 변경 지원

2. **모던 UI/UX 전면 개편 (모바일 바텀시트 & 데스크톱 사이드바 + 다크모드)**
   - **커스텀 말풍선 지도 마커**: 건물명과 남/여/공용 비밀번호를 지도 위에서 한눈에 확인
   - **원클릭 비밀번호 복사**: 남자(`🔵`), 여자(`🔴`), 공용(`🔑`) 비밀번호 배지 클릭 시 클립보드 즉시 복사
   - **카카오맵 · 네이버 지도 · 구글 지도** 길찾기 원클릭 연동 및 화장실 정보 공유 기능
   - 라이트 모드 / 다크 모드(`🌙 다크`) 전환 지원

3. **진짜 '가까운 변소 찾기' (급똥 응급 모드) & 검색/필터**
   - 내 현재 GPS 위치를 기반으로 모든 화장실까지의 **실제 직선거리(m/km) 및 도보 예상 시간(분)** 자동 계산
   - **🚨 급똥! 가까운 변소 찾기** 클릭 시 가장 가까운 1순위 화장실로 즉시 이동 및 비밀번호 표시
   - 건물명/상호명/동네 실시간 검색, `내 주변 가까운 순`, `남녀분리`, `1층 화장실`, `⭐ 즐겨찾기` 필터, 지역 빠른 이동 바 제공

4. **화장실 추가 / 제보 및 지도 위치 피커**
   - **🎯 지도에서 직접 찍기**: 지도를 클릭해 정확한 화장실 위치를 지정하고 주소(동네명) 자동 입력
   - 남녀분리 여부(남/여 비번 각각 입력), 휴지 구비 여부(`🧻 휴지 구비` / `⚠️ 휴지 개인지참`), 층수, 특이사항 등록

5. **무료 클라우드 DB (Supabase) 실시간 연동 아키텍처**
   - **PostgreSQL `pgcrypto` (bcrypt 해싱) + Row Level Security (RLS) + `SECURITY DEFINER` RPC 함수**를 통해 프론트엔드 코드에 비밀번호나 화장실 데이터가 노출되지 않도록 서버사이드 보안 검증 구현
   - Supabase 연동 전에도 즉시 모든 기능을 사용할 수 있는 **로컬 스토리지 하이브리드 엔진** 탑재

## ☁️ 무료 클라우드 DB (Supabase) 3분 연동 가이드

여러 사용자(친구/지인)와 실시간으로 계정 및 화장실 제보 데이터를 공유하려면 무료 **Supabase**를 연결하세요.

1. [Supabase](https://supabase.com)에 접속해 무료 계정으로 로그인 후 **`New Project`**를 생성합니다.
2. 좌측 메뉴 **`SQL Editor`** → **`New Query`**를 클릭합니다.
3. 이 저장소의 [`supabase/schema.sql`](./supabase/schema.sql) 파일 내용을 전체 복사하여 붙여넣고 **`Run`**을 클릭합니다.
   - *(테이블, 보안 RLS 정책, 로그인/관리자 RPC 함수, 초기 `admin` 계정 및 기존 화장실 16곳이 자동으로 생성됩니다.)*
4. 좌측 메뉴 **`Project Settings` (톱니바퀴) → `API`**로 이동하여 다음 두 값을 복사합니다:
   - `Project URL` (예: `https://xxxxxx.supabase.co`)
   - `Project API Keys` 중 **`anon` `public`** 키
5. [`js/config.js`](./js/config.js) 파일의 `SUPABASE_URL`, `SUPABASE_ANON_KEY`에 붙여넣고 GitHub에 푸시하면 모든 접속자에게 실시간 클라우드 DB가 적용됩니다!
   - *(또는 웹 화면의 `👑 관리자 센터 → 무료 클라우드(Supabase) 연동` 탭에서도 바로 입력해 테스트할 수 있습니다.)*
